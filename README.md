## 📖 Overview

The **Travelling Website** is a frontend web development project designed to make travel planning easier and more convenient.

Users can explore different destinations, search and filter travel options, view tour packages, browse hotels and flights, and organize their travel itineraries.

The project also includes frontend interfaces for user authentication and an administrative dashboard to manage users, bookings, and travel packages.

The primary focus is on creating an attractive, user-friendly, and responsive interface using core web development technologies.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A web browser (Chrome, Firefox, Edge, etc.).
- Visual Studio Code (recommended).

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd travelling-website
```

**3. Open the project**

Open the project folder in Visual Studio Code.

**4. Run the website**

Open `index.html` in your browser or use the Live Server extension in VS Code.
